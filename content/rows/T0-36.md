what_failed: "An entry in protected_resources in your sign-in server's OAuth metadata is not a text value, does not start with https://, or has a fragment, the part after a #. An entry with no path that has a trailing slash, a query, the port 443, or for a 0.3 or 0.4 file any port, gets a note instead: if it is one of your domains, write it as https:// and the domain."
why_it_matters: "Every address the protocol uses must be HTTPS, and an address that names a resource has no fragment. Your sign-in server may list other resources too, such as MCP servers, but each domain it serves must appear as https:// and the domain, with no path or trailing slash, or assistants on that domain will not trust it. This check does not apply to 0.1 and 0.2 files."
