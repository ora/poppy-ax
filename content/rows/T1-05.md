what_failed: "The MCP server answered an MCP 2025-06-18 initialize with no token with a 401 whose challenges do not all carry resource_metadata. For a 0.2 file, it also needs a Bearer challenge, plus a DPoP challenge when its metadata lists DPoP algorithms. A server that refuses it first, with invalid_session, version_unsupported or extension_required, or speaks only MCP 2026-07-28, reads not tested."
why_it_matters: "MCP clients find where to get a token from the server's protected resource metadata, so every challenge on a 401 points to it. A server that answers invalid_session, or serves the call with no token, has no challenge to check. MCP 2026-07-28 drops the initialize handshake for metadata on each request, so a server that speaks only that version cannot be graded this way yet."
