what_failed: "An MCP server listed in apis has protected resource metadata (RFC 9728) whose resource is not the server's url, or that lists sign-in servers leaving out your issuer. A server whose metadata address answers 404 offers no account access and is not counted."
why_it_matters: "MCP clients find where to get a token from this metadata, at the server's own metadata address or, when that has none, at the address a 401 from the server points to, and the checker reads it the same way. Its resource must equal the server's url in poppy.json, and a server that offers account access must name your issuer."
