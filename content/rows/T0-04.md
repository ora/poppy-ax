title: "Version a 1.0 agent can use"
what_failed: "protocol_version names a draft before 1.0, such as 0.4, and supported_versions links no 1.0 document at an HTTPS address on the host that served poppy.json. Or protocol_version is missing, is a number such as 1.0 without quotes, or is not written as major.minor, such as \"1\", \"1.0.0\" or \"1.00\", which also stops the other checks. A later 1.x version passes; a later major reads not tested."
why_it_matters: "An assistant uses only a file whose major version it supports, so one built for 1.0, the latest published version, does not use a 0.x file (spec 3.4). Set protocol_version to \"1.0\", or link a 1.0 document by HTTPS on the same host as poppy.json in supported_versions. Either way the other checks grade poppy.json itself by the 1.0 rules, not the linked document."
